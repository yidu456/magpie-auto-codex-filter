接入与退出

  1. 确认 Magpie 地址与 Codex 配置文件，保存接入设置，再开启核心过滤。
  2. 首次接入、更换端口或恢复地址后，重开 Codex 让它读取配置。不要与旧版同时接管同一份配置。
  3. 关闭核心是字节直通，不清理、不重试、不暂存，也不解析响应获取 Token；不等于断开接入。
  4. 断开或退出会恢复本程序改写的地址。网页关闭不停止服务，再次双击 EXE 可重新打开。

网页端口和管理令牌保存后仅在下次启动生效；当前令牌继续可用。请保留配置与恢复文件，不要公开令牌。

如何选择响应交付

整轮暂存（默认）
等本轮成功再交付正文与工具事件；失败尝试不交付，可在预算内恢复。手工配置的两个保护布尔值均为 true 时也优先暂存。
保护首段流式
在首次内容增量前检查并恢复早期错误，然后持续流式交付。首次内容交付后不再重试、清理或重放工具；晚期失败仍记作失败，不因 HTTP 200 视为成功。
直接流式
即时转发，不拦截流内错误；开始实际交付后无法重试或撤回工具事件。

暂存与首段保护的交付前缓存最多 64 MiB。保活只在核心启用且尚未实际交付时发送空进度，不改变模型生成速度。设置仅作用于新请求，执行中的请求保留原策略。

历史清理与恢复边界

暴力清理先移除历史推理与可移除 ID；条件清理先保留，在明确的资源归属或有效 HTTP 400 invalid_encrypted_content 错误后才清理；不清理始终保留历史，但仍使用已启用的其他恢复。

Magpie 的 store、上下文与压缩委托保持不变；消息正文、工具结果与 call_id 配对不会因为切换选项被删除。实际条件清理才使用安全移除规则。

网络处理覆盖连接失败、空闲超时、明确断连、中继错误 cc_switch_forward_failed / bad_response / server_error，以及未归类的 JSON 对象 HTTP 5xx；不是任意 HTML 5xx。流式中断与无详情失败使用独立开关，ALB 400 只匹配已知网关页。

HTTP 401/403、鉴权、权限、账单、余额、配额和无效参数等业务错误不进入通用网关重试；历史密文错误也不会被通用 5xx 兜底绕过。关闭一类处理不会转入另一类继续重试。

资源最多 5 次、临时限流最多 20 次、网络 / 中继 / 断流共享最多 10 次、无渠道最多 10 次；每个请求合计最多额外 20 次，期限 30 分钟。遵守 Retry-After 最小等待，取消立即终止等待，交付后永不重放。WebSocket 暂不支持。

如何阅读指标

开始、完成、使用量和重试各按发生时的本地日期计入；跨午夜的活动请求不会中断。首次实际交付与总时长包含上传；分布提供区间与均值，不生成虚构的百分位。

Token 仅计有效 response.completed.usage，核心关闭、缺失或检查不可用时显示未观测，而非零。可选总量与缓存字段只覆盖实际提供该字段的观测；有效观测的零仍为零。这不是账单，也不承诺速度、成本或恢复率改善。

日汇总每分钟及正常退出时写入本地 metrics.json，同日本机重启可恢复；曲线与最近请求只在内存，重启清空。异常退出可能丢失上次检查点后的数据与排队日志，原子替换不是断电保证。

曲线最多保留最近 180 分钟有事件的窗口，活动记录最多 1000 条，结束记录最多 200 条；超限或日志丢弃会显示诊断。计数不包含请求正文、响应正文、密钥或工具数据。
